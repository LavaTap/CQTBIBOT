# 百度 Python 编码规范 — 紧凑检查清单

> 完整规范含示例和解释，见 `md/baidu-python-style-guide.md`
> 项目级约束见 `CLAUDE.md` 第六节

## 语言规范

| ID | 级别 | 规则 |
|----|------|------|
| | 建议 | 禁止 `from xxx import yyy` 导入类/函数（yyy 只能是 module/package） |
| PY002 | 建议 | 禁止 `from xxx import *` |
| PY003 | 建议 | import 必须使用全路径，禁止相对路径和 sys.path.append |
| PY004 | 强制 | 禁止双参数/字符串形式抛异常（`raise E, msg` / `raise "msg"`） |
| | 强制 | 自定义异常必须继承模块内 `Error` 基类（`Error` 继承 `Exception`） |
| | 强制 | 禁止 `except:` 捕获所有异常（重新抛出除外） |
| | 建议 | 捕获 `Exception` 须记录日志 |
| PY007 | 强制 | 捕捉异常用 `as` 语法，禁止逗号语法 |
| | 建议 | try 中代码尽可能少 |
| | 建议 | 用 `finally` 清理资源 |
| | 强制 | 禁止全局变量（脚本默认参数、模块级常量除外） |
| | 强制 | 全局变量须写在文件头部 |
| | 建议 | 构造函数应尽量简单 |
| PY011 | 建议 | 列表推导：mapping/loop/filter 单行，禁止多层 loop/filter |
| | 强制 | 容器只读遍历用内置迭代方法，不用返回 list 的方式 |
| PY013 | 强制 | 用 `in`/`not in` 判断元素存在，不用 `has_key` |
| PY014 | 建议 | lambda 仅限一行 |
| | 建议 | 条件表达式仅一行，禁止嵌套 |
| PY016 | 建议 | 默认参数仅用基本类型字面常量（int/bool/float/str/None） |
| | 强制 | 函数返回值 ≤3 个，超过用 namedtuple/dict 包装 |
| PY018 | 强制 | 禁止 `==`/`!=` 判断 None，用 `is`/`is not` |
| | 强制 | bool 类型禁止 `== True`/`== False`，用 `expr`/`not expr` |
| | 强制 | 整数零判断用 `== 0`，禁止 `not expr` |
| | 建议 | 装饰器仅用于 @property/@classmethod/@staticmethod/测试/第三方库 |
| | 强制 | 禁止在派生类改写 property 实现 |

## 风格规范

| ID | 级别 | 规则 |
|----|------|------|
| PY021 | 建议 | 禁止分号结束语句 |
| PY022 | 建议 | 一行一条语句 |
| PY023 | 强制 | 每行 ≤120 字符 |
| PY024 | 强制 | 函数 ≤120 行 |
| | 建议 | 除优先级/tuple/行连接外，避免冗余括号 |
| | 强制 | 4 空格缩进，禁止 tab |
| | 强制 | 多行对齐：与首行对齐，或首行留空从第二行缩进 4 空格 |
| PY027 | 建议 | 文件级定义间两空行，类方法间一空行 |
| PY028 | 建议 | 括号内侧不加空格 |
| PY029 | 建议 | 左括号前不加空格 |
| PY030 | 强制 | 逗号/分号/冒号前无空格，后一空格 |
| PY031 | 强制 | 二元运算符前后各一空格 |
| PY032 | 强制 | 关键字参数/默认值等号前后不加空格 |
| PY033 | 强制 | docstring 用三双引号 |
| | 强制 | 对外接口必须有 docstring |
| PY034 | 强制 | docstring 至少含功能/参数/返回值/异常说明 |
| | 强制 | 每文件必须有文件声明（版权/功能/作者） |
| | 建议 | TODO 格式：`# TODO: 描述$负责人$YYYY-MM-DD$` |
| PY037 | 建议 | 每行只导入一个库 |
| | 建议 | import 顺序：标准库 → 第三方 → 自有，各部分间一空行 |
| PY039 | 强制 | 类名首字母大写驼峰（含异常） |
| | 强制 | 常量全大写下划线分隔 |
| | 强制 | 其它全小写下划线分隔 |
| | 建议 | protected 单下划线，private 双下划线 |
| PY043 | 建议 | 禁止双下划线开头结尾名（`__init__` 等除外） |

## 编程实践

| ID | 级别 | 规则 |
|----|------|------|
| | 建议 | 模块主程序以 `#!/usr/bin/env python` 开头 |
| | 强制 | 含非 ASCII 字符须声明编码 |
| | 强制 | 只用 UTF-8 或 GB18030 |
| PY046 | 建议 | 无基类须继承 object |
| | 建议 | 字符串格式化用 `%`/`format`，简单拼接用 `+` |
| | 建议 | 字符串列表拼接用 `join` |
| | 建议 | 文件/socket 用 `with` 显式关闭 |
| | 建议 | 主程序检查 `__name__ == '__main__'` |
| | 建议 | 测试代码放 test 目录，命名 `xxx_test.py` |
| | 建议 | 使用 logging 库，推荐日志格式含级别/时间/文件/行号 |
